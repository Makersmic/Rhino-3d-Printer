# Maintenance

> **Maintenance tracking now exists.** The [Tool Manager](https://github.com/Makersmic/Toolhead_Manager) portal tracks tasks by production hours, jobs, tool
> swaps or calendar time - for the machine and for every toolhead - with a work log and dashboard. The list below was
> the original plan and is covered by its Task Library.

## Scheduled maintenance items
- Belt stretch
- Bearings
- Leadscrew cleaning and lubricating
- General cleaning of the underside

## Service bay (idea)
When i think about  a maintenance bay, a user may put a tool into said bay and the user be able to service a tool.  Functions that
a service bay would need to be facilitate all of the tools by default.  The bay would need meet all of the requirements that umbilical holds while also having the ability to test 
components such as endstops or other possible hardware.
